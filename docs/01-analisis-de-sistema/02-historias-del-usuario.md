# Historias de usuario

Formato: **Como** [actor], **quiero** [acción], **para** [beneficio].

| ID | Historia de usuario | Criterio de aceptación principal |
|---|---|---|
| **HU01** | Como dueño de mascota, quiero crear un perfil para mi mascota, para presentarla a la comunidad. | El perfil queda visible según la privacidad elegida (público, solo seguidores o privado). |
| **HU02** | Como dueño de mascota, quiero publicar fotos y videos de mi mascota, para compartir su día a día. | La publicación aparece en el feed de quienes siguen a la mascota, en orden cronológico. |
| **HU03** | Como dueño de mascota, quiero enviar mensajes directos a otro dueño, para coordinar en tiempo real algún tema relacionado con nuestras mascotas. | El mensaje llega al destinatario conectado sin recargar la página. |
| **HU04** | Como dueño de mascota, quiero reportar que mi mascota se perdió, indicando su última ubicación, para que la comunidad cercana me ayude a encontrarla. | Al reportar, el sistema responde de inmediato y la alerta se distribuye de forma asíncrona. |
| **HU05** | Como dueño de mascota, quiero recibir una alerta cuando se reporte una mascota perdida cerca de mí, para ayudar a reunirla con su dueño. | Recibo la alerta solo si estoy dentro del radio configurado del reporte. |
| **HU06** | Como moderador, quiero revisar el contenido reportado por la comunidad, para mantener un espacio seguro. | Puedo ver el contenido reportado, descartarlo o suspender la cuenta responsable, y la acción queda en la bitácora. |
