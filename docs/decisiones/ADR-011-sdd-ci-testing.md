# ADR-011: SDD, pruebas y CI/CD

- **Estado:** Aceptada
- **Decisión:** especificaciones Markdown como fuente de verdad; cambios pequeños, Conventional Commits, revisión de PR, pruebas unitarias, arquitectura, integración, contrato, seguridad y carga programada; Docker Buildx para ARM y GitHub Actions.
- **Alternativas:** documentación posterior al código y despliegues manuales.
- **Consecuencias:** trazabilidad y reproducibilidad; mayor disciplina y tiempo inicial de pipeline.
